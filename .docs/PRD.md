# 프로젝트 개요

## 프로젝트명
마이링크 (MyLink)

## 목적
여러 개의 흩어진 링크(소셜 미디어 프로필, 블로그, 포트폴리오, 개인 웹사이트 등)를 단 하나의 직관적인 페이지로 모아 사용자들에게 효과적으로 공유할 수 있는 서비스 제공.

## 대상 사용자
- **소프트웨어 개발자 및 프로그래머:** 깃허브(GitHub), 기술 블로그(Velog, Tistory), 포트폴리오 사이트 등 다양한 개발 관련 링크를 한곳에 매끄럽게 정리하고 싶은 분.
- **오픈소스 콘트리뷰터 및 테크 인플루언서:** 자신이 기여한 오픈소스 프로젝트 생태계, 컨퍼런스 발표 자료, 기술 유튜브 링크 등을 효과적으로 공유하려는 분.
- **예비 개발자(취업/이직 준비생):** 노션(Notion) 이력서, 알고리즘 프로필(백준/프로그래머스), 개인 토이 프로젝트 배포 링크를 하나의 페이지로 취합하여 채용 담당자에게 일목요연하게 전달하려는 분.

# 각 기능 상세 설명

## 1. 계정 및 인증 (Firebase 연동)
- **원클릭 구글 로그인 (필수):** 사용자의 진입 장벽을 낮추기 위해 번거로운 회원가입 대신, **Firebase Authentication** 기반의 구글 로그인만을 독점 제공합니다. 모든 계정 관리는 무료로 이루어집니다. 
- **보안 및 세션:** 로그인 상태가 브라우저에 안전히 유지되며 다시 방문해도 즉시 본인 링크를 관리할 수 있습니다.

## 2. 프로필 고유화 및 브랜딩
- **정보 설정 (필수):** 관리자 화면(어드민) 상단에서 프로필 이미지, 닉네임, 그리고 두 줄 이내의 자신을 돋보이게 할 텍스트(Bio)를 직관적으로 설정합니다.
- **접속 URL 배정 (필수):** 가입 시 초기 설정하거나, 혹은 계정 UID를 활용해 중복되지 않는 본인만의 고유 링크 주소가 부여됩니다. 

## 3. 링크 관리 대시보드
- **쉬운 링크 CRUD (필수):** 사용자는 '표시될 버튼 이름'과 '이동할 목적지 URL'만 입력하면 즉시 링크를 추가할 수 있습니다. 
- **드래그 앤 드롭 정렬 (필수):** 목록 좌측의 핸들을 마우스로 잡고 위아래로 끌어다 놓으면 실시간으로 퍼블릭 웹에 순서가 즉시 동기화됩니다. 
- **노출/비노출 토글 (선택):** 만료된 이벤트 링크거나 일시적으로 숨기고 싶은 링크는 굳이 삭제하지 않고 바로 On/Off 할 수 있습니다. 편의성을 극대화합니다.
- **소셜 전용 위젯 배치 (선택):** 유튜브, 깃허브, 인스타그램 URL은 큼직한 버튼이 아니라 하단에 깔끔한 조각 아이콘 상태로만 제공하는 특수 위젯 공간을 지원합니다.

## 4. 퍼블릭 링크 뷰어 (소비자 관점)
- **모바일-First 뷰어 (필수):** 링크트리류 서비스 특성상 방문자의 90% 이상은 인스타그램/틱톡 모바일 앱을 통해 접속합니다. 따라서 데스크톱 환경에서도 스마트폰 화면폭(최대 480px~500px 수준) 정도로 가운데 정렬된 세로형 UI를 기본으로 제공합니다. 
- **공유하기 버튼 (선택):** 쉽게 주변 사람에게 해당 인플루언서나 브랜드 정보를 전달하도록 URL 복사 기능을 제공합니다.

## 5. 디자인 시스템 (shadcn/ui)
- **트렌디하고 미니멀한 UI (필수):** Radix UI 기반인 **shadcn/ui**의 기본 세팅을 채택, 화려하고 복잡한 요소보다는 정보 전달과 클릭 유도가 핵심인 깔끔한 UI를 제공합니다.
- **다크모드 지원 (필수):** 사용자의 운영 체제 또는 기기 설정 모드 테마에 맞춰 프로필 페이지 또한 자연스럽게 다크모드/라이트모드로 전환되게 설계됩니다.

## 6. 제공되는 향후 비전 및 통계 기능
- **데이터 분석(Analytics) (선택/향후 반영):** 개별 링크가 실제로 몇 번이나 클릭되었고, 사람들이 어느 링크에 흥미가 있었는지를 파악하여 마케팅 결정을 돕는 대시보드 그래프 기능을 고려해볼 수 있습니다. 이를 통해 서비스 자체의 매력도가 매우 상승합니다.
